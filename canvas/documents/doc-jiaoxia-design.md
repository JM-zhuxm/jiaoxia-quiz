# 科目一 · 闯关（长盛驾校）

## 1. 玩家幻想

「我刚在长盛驾校报名，今天要在手机上刷一遍科目一。每一关 10 道真实题，20 秒一题，像考场一样紧张。刷够 90 分才算过，拿到驾照就出发。」

- **身份**：长盛驾校学员，备考科目一（机动车驾驶人理论考试）。
- **场景**：手机竖屏，一次一关，2~4 分钟一局，随时能重来。
- **情绪**：轻度紧张（倒计时）+ 明确的成长反馈（分数、等级、连续闯关）。

## 2. 核心循环

```
标题页 → 开始闯关 → 题目页（读题 → 看配图 → 选答案 → 倒计时）
                 ├─ 答对：+10 分、绿勾、即时反馈
                 ├─ 答错：-10 分、抖动、立即显示正确答案与解析
                 └─ 超时：-10 分、按答错处理
        → 解析面板（判定 + 正确对勾 + 你的选择叉号 + 正确答案 + 逐题解析 + 下一题）
        → 第 10 题结束 → 成绩页（分数 + 等级 + 统计 + 错题回顾）
        → 再闯一关（直接进入第 N+1 关，题库重新随机抽题） / 返回首页
```

- **推进**：每一关 10 题，来自 39 题内置题库；过关后关卡 +1，题库重新洗牌抽题，循环往复。
- **累计**：跨关累计总分 + 单关最佳成绩 + 已闯关数写入 `localStorage`（键 `jiaoxia-quiz-progress`），标题页展示。

## 3. 规则与数值

| 项 | 数值 |
| --- | --- |
| 题库 | 39 道真实科目一单选题（4 选 1），含正确答案与解析；答案位置按 A/B/C/D 轮转，避免全选同一项 |
| 每关题量 | 10 题 |
| 单题限时 | 20 秒（顶部居中倒计时环 + 剩余秒数，≤5 秒变红并脉冲缩放） |
| 答对 | +10 分 |
| 答错 | -10 分 |
| 超时 | -10 分（按答错处理，判定横幅显示「超时未答」） |
| 单关满分 | 100 分 |
| 合格线 | 90 分（与真实科目一一致；**仅 S 级判定为合格**） |

**等级**（单关得分）：

| 等级 | 分数 | 称号 | 合格 | 评语 |
| --- | --- | --- | --- | --- |
| S | 90~100 | 一次过 | 合格 | 稳得像老司机，科目一稳过。 |
| A | 80~89 | 高分学员 | 未合格 | 底子扎实，把错题再啃一遍就满分。 |
| B | 70~79 | 稳步前进 | 未合格 | 合格线附近，上考场别紧张。 |
| C | 60~69 | 需要加练 | 未合格 | 错题集中在法规和标志，回炉重刷。 |
| D | 0~59 | 建议重修 | 未合格 | 别急着约考，先把题库刷两遍。 |

成绩页在分数右侧额外显示「合格 / 未合格」徽标，让 80 分这类「高分但没过」的结果一眼可辨。

## 4. 屏幕与视觉规范

- **画布**：Phaser 3，基准分辨率 720×1280（9:16），`Scale.FIT` + `CENTER_BOTH`，任何视口都不出现横向滚动；宽屏下画布水平居中（居中只由 Phaser 的 margin 实现，不与 flex 居中叠加）。
- **主题**：浅色背景 `#EEF3FB`，白色卡片 + 软阴影，圆角 22~34px；交警蓝 `#2F6BFF` 为主色，答对绿 `#16A34A`、答错红 `#E5484D`、倒计时预警琥珀 `#F59E0B`、CTA 琥珀橙 `#FF9F1C`。
- **字体**：`"PingFang SC" / "HarmonyOS Sans SC" / "Microsoft YaHei" / system-ui`，题干 34px，选项 30px，HUD 26px，标题 76px——移动端大字号优先。
- **层级**：只保留当前决策所需信息常驻；解析面板按需从底部升起，答题后盖住选项区，题干始终可见。
- **CTA**：底部常驻按钮「长盛驾校·从化学车」，三个页面都有，点击跳转 `https://cargo20.com/`。
- **插画**：主视觉与教学配图统一使用生图模型产出的扁平卡通插画（暖色浅底、圆润造型、无文字），与代码绘制的卡片/图标混排时保持同一套圆角与暖色描边。

### 屏幕要点

1. **标题页**：品牌胶囊 + 主标题「科目一闯关」+ 生成的封面插画（学员在教练车内认真看路，置于白色圆角卡内并轻微浮动）+ 三个规则卡（20 秒一题 / 答对 +10 / 答错 -10）+ 历史最好分 + 主按钮「开始闯关」。
2. **答题页**：顶部 HUD（左「第 N 关」胶囊 / 中倒计时环 / 右分数胶囊）+ 题号 + 10 段进度条；中部题干白卡（3 道题在卡内顶部附教学配图，暖色底框，按可用高度自适应缩放）；下部 4 个大号选项卡（A/B/C/D 圆形徽标 + 文本，选错时抖动）。
3. **解析面板**：判定横幅（✓ 正确 +10 / ✗ 错误 -10 / ⏱ 超时 -10）+ 绿勾「正确答案」+ 红叉「你的选择」+ 逐题解析 + 「下一题 ›」（最后一题为「看成绩 ›」）。
4. **成绩页**：金牌徽章（金环 + 暖色内盘 + 顶部金星 + 生成的车辆插画，整体缩放脉冲）+ 分数大字 + 「合格 / 未合格」徽标 + 等级胶囊与评语 + 统计四格（答对/答错/超时/用时）+ 累计四格（本关/累计/最好/已闯关数）+ 错题回顾 + 「再闯一关」「返回首页」。

## 6. 技术方案

- **栈**：Vite 5 + TypeScript 5 + Phaser 3.90，无后端、无网络依赖；图片为随包发布的本地静态资源。
- **状态**：规则与计分放在 `src/core/quiz.ts`（纯逻辑，可单测），Phaser 场景只负责表现；跨场景状态在 `src/core/state.ts`，进度持久化在 `src/core/progress.ts`。
- **场景**：`TitleScene` → `QuizScene` → `ResultScene`；5 张插画在 `TitleScene.preload()` 统一预载（不额外加 Boot 场景，避免启动期场景切换带来的布局审计噪音），纹理留在全局 TextureManager 供后续场景复用。
- **插画接入**：`ART` 清单统一定义纹理 key、`public` 相对路径、裁剪区域与显示尺寸；先 `setCrop()` 再 `setDisplaySize()` 保持原图比例；题干卡按剩余高度等比缩放配图，空间不足时省略，保证题干与选项永不被压住。
- **输入**：点按选项卡作答；键盘 `A/B/C/D` 或 `1-4` 选答案，`Space/Enter` 进入下一题；触摸与鼠标统一走 Phaser pointer。
- **持久化**：`localStorage` 存累计分、最好成绩、已闯关数（隐私模式下静默降级）。
- **构建**：`npm run build` = `tsc --noEmit && vite build`，产物 `dist/`，`base: './'` 保证任意目录可发布；`public/art/` 会随构建复制到 `dist/art/`。
